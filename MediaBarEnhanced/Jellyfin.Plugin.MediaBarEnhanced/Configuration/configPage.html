输入你希望在轮播中作为默认内容显示的条目 ID，可用换行或逗号分隔。

提示：直接粘贴完整的 Jellyfin 条目 URL，ID 会被自动提取！

动态过滤器：可以使用前缀直接筛选媒体库中的条目：
  • genre:Action — 按流派筛选（如 Action、Comedy）。
  • -genre:Horror 或 !genre:Horror — 排除某个流派 （黑名单，例如配合 -genre:Horror, Thriller 使用 genre:Comedy 打造适合全家观看的媒体栏）。
  • tag:Halloween — 按标签筛选 （如 Halloween、Favorite）。
  • -tag:gore 或 !tag:gore — 排除带有 特定标签的条目。
  • studio:Pixar — 按制作公司筛选（如 Pixar、Marvel Studios、A24）。
  • person:Tom Hanks — 按演员、导演或幕后人员筛选 （也可用 actor:、director:）。
  • year:2024 — 按发行年份筛选。
  • years:2000-2010 或 years:2000s — 按 年份范围或年代筛选。
  • years:2020+ — 按最早年份筛选。
  • released:90d — 筛选最近 90 天内首播的 条目。
  • rating:PG-13 或 rating:16 — 按 官方/家长分级筛选。
  • rating:>=7.5 或 rating:8+ — 按 最低社区评分（IMDb 分数）筛选。
  • rating:<=12 — 按最高家长分级筛选。
可以用逗号或换行列出多个过滤器。同一类型的多个值之间以 OR（并集）组合；不同类型的过滤器（如流派 AND 年份 AND 制作公司）之间以 AND 组合。 过滤器前缀可与常规 ID、合集名称和播放列表名称自由混用。

手动指定预告片/视频：在方括号中指定 YouTube URL 或 Jellyfin 条目 ID（如主题/背景图视频）：
例如 ID 简介 [https://youtu.be/...] 或 ID [JellyfinItemId] 简介
  • YouTube URL：播放来自 YouTube 的远程预告片。
  • Jellyfin 条目 ID：使用原生播放器播放其他媒体库条目的视频 （如主题/背景图视频）。
可以在 ID 后面添加简介，使用任意分隔符，如空格、竖线（|）或短横线（-）：
例如 ID 简介 或 ID | 简介。
注意：如果使用合集/播放列表名称（而非 ID）并附带简介，则必须使用竖线（|）分隔符； 且分隔符不能是十六进制字符（0-9、a-f）。

查找 ID：查看浏览器中条目页面的 URL 即可。
示例： https://your-jellyfin-url/web/#/details?id=your-item-id&serverId=your-server-id

合集与播放列表：输入合集或播放列表的名称，即可获取其中的所有条目（采用第一个匹配结果）。
注意：目前名称解析成功时不会有任何反馈； 请在主页上确认是否显示了正确的条目。
